# Portada de LinkedIn

- `portada-linkedin-oscura.png` y `portada-linkedin-clara.png`: listas para subir (3168×792, proporción 4:1 de LinkedIn al doble de resolución).
- `banner.html`: fuente editable. Ábrelo en el navegador; `?theme=light` cambia al tema claro y `?preview` simula el avatar y el botón de edición para revisar que nada quede tapado.

El texto queda a la derecha del avatar (x ≥ 620 px de 1584) para que no lo cubra la foto de perfil ni en escritorio ni en el celular.
